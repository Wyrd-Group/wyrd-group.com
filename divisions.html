Nestar

Governed AI for companies and institutions.

What an institution buys is a private agent environment: every agent has an identity and a mandate, sensitive actions require approval, private memory stays within policy, cloud use is bounded, actions create proof, access can be revoked, and deployment can be repaired or rolled back.

Nestar is not ICARUS. ICARUS is the authority substrate; Nestar is the enterprise product built with it.

Mandate Network
The authorization network for agentic finance.
Integration program
What it does

Proves whether an AI agent is authorized to request a value-moving action before the request reaches a bank, card network, payment API, tokenization platform, FX rail or trade-finance workflow.

Where the boundary sits

Mandate Network does not move money. It does not hold funds, issue money or act as a bank, payment rail, exchange or currency issuer.

Family

The distinction

A card network asks whether a card can pay. Mandate asks whether this agent is allowed to request this payment, for this reason, under this owner's rules, right now — and whether it can be proved afterwards.

The boundary, stated first

CORP-US spans civil protection through to restricted defense support. Restricted capability requires lawful customer authority, licensing, export review, procurement rules, independent safety and legal controls, explicit human command and domain-specific approval. Those programs are named and placed below and on the restricted & partner register; their operational content — targeting, weapons, kill-chain logic, offensive autonomy, intrusion methods — is not published in any Wyrd material, at any tier.
